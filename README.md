# HackerOne Scope Monitor 🚀

Automate tracking of **new programs and scope expansions** on HackerOne using the **official API**, with Telegram notifications.

## Features
- Official HackerOne API (no scraping)
- Structured scope diffing
- Detects new in-scope assets
- Telegram alerts
- Safe snapshot persistence

## Requirements
- Python 3.9+
- HackerOne account with API token
- Telegram bot
